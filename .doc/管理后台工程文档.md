# 管理后台工程文档

## 1. 项目概述

管理后台工程位于 `adminPanel/`，是 AI 试戴间的独立管理后台系统。它为运营人员提供：

- 仪表盘数据统计展示（用户总数、活跃用户、生成次数等）。
- 用户管理（查看用户列表、配额使用情况、用户状态等）。
- 推荐图管理（管理首页展示的推荐配图）。

管理后台是独立于前台 `frontEnd/` 的项目，从 commit `cfcb1e9` 开始拆分，使用独立的端口和路由。

## 2. 技术栈

- 构建工具：Vite 6
- 前端框架：React 19
- 语言：TypeScript 5.7
- 样式：Tailwind CSS 4 + `tw-animate-css`
- UI 组件：shadcn/ui 风格组件 + Radix UI
- 路由：React Router v6
- 图标：lucide-react
- 表单相关依赖：react-hook-form、zod、@hookform/resolvers
- 主题依赖：next-themes
- 图表：recharts
- 通知：sonner + 本地 `use-toast` / Toaster 组件
- 包管理：npm

## 4. 启动与构建

路由配置：

```text

```

### 8.1 管理员路由守卫

文件：`src/routes/admin-route.tsx`

`AdminRoute` 组件会检查：

1. 用户是否已登录（`isAuthenticated`）。
2. 未登录用户重定向到 `/login`。
3. 已登录用户正常渲染子组件。

注意：当前路由守卫主要检查登录状态，后端 API 会验证用户角色是否为 `admin`。

## 9. 认证上下文

文件：`src/context/auth-context.tsx`

使用 `useReducer` 管理认证状态，提供以下功能：

### 9.1 状态

| 状态 | 类型 | 说明 |
| --- | --- | --- |
| `user` | `User \| null` | 当前用户信息 |
| `isLoading` | `boolean` | 是否正在登录/加载 |
| `isAuthenticated` | `boolean` | 是否已登录 |

### 9.2 方法

| 方法 | 说明 |
| --- | --- |
| `login(login, password)` | 登录（login 可以是用户名或邮箱） |
| `register(username, email, password)` | 注册 |
| `logout()` | 登出 |
| `refreshUser()` | 刷新当前用户信息 |

### 9.3 持久化

- Access Token 和 Refresh Token 存储在 `localStorage`。
- 用户信息也缓存在 `localStorage`，初始化时优先读取。

## 10. 认证 API

文件：`src/services/auth.ts`

封装函数：

| 函数 | 方法和路径 | 说明 |
| --- | --- | --- |
| `login(credentials)` | `POST /api/auth/login` | 登录 |
| `register(data)` | `POST /api/auth/register` | 注册 |
| `refreshTokens()` | `POST /api/auth/refresh` | 刷新 Token |
| `getCurrentUser()` | `GET /api/auth/me` | 获取当前用户 |
| `logout()` | `POST /api/auth/logout` | 登出 |
| `changePassword(...)` | `POST /api/auth/change-password` | 修改密码 |
| `forgotPassword(email)` | `POST /api/auth/forgot-password` | 忘记密码 |
| `resetPassword(...)` | `POST /api/auth/reset-password` | 重置密码 |
| `getQuota()` | `GET /api/users/quota` | 获取配额 |
| `getRecommendations()` | `GET /api/presets/recommendations` | 获取推荐图 |

### 10.1 Token 刷新机制

当 API 返回 401 时：

1. 如果当前不在刷新中，调用 `refreshTokens()` 获取新 Token。
2. 同时其他 401 请求会订阅刷新完成事件。
3. 刷新成功后，使用新 Token 重试原请求。
4. 刷新失败则清除本地认证状态并重定向到登录页。

## 11. 管理后台 API

文件：`src/services/admin.ts`

所有管理后台 API 都挂载在 `/api/admin` 路径下，需要管理员权限。

### 11.1 统计

| 函数 | 方法和路径 | 说明 |
| --- | --- | --- |
| `getStats()` | `GET /api/admin/stats` | 获取仪表盘统计数据 |

### 11.2 用户管理

| 函数 | 方法和路径 | 说明 |
| --- | --- | --- |
| `getUsers(params)` | `GET /api/admin/users` | 获取用户列表（支持分页、搜索） |
| `getUser(id)` | `GET /api/admin/users/{id}` | 获取单个用户详情 |
| `createUser(data)` | `POST /api/admin/users` | 创建用户 |
| `updateUser(id, data)` | `PUT /api/admin/users/{id}` | 更新用户信息 |
| `updateUserQuota(id, quotaTotal)` | `PUT /api/admin/users/{id}/quota` | 更新用户配额 |

### 11.3 推荐图管理

| 函数 | 方法和路径 | 说明 |
| --- | --- | --- |

| `getRecommendation(id)` | `GET /api/admin/recommendations/{id}` | 获取单个推荐图详情 |
| `createRecommendation(data)` | `POST /api/admin/recommendations` | 创建推荐图 |

## 12. 页面说明

### 12.1 登录页

文件：`src/pages/login.tsx`

功能：

- 用户输入登录名（用户名或邮箱）和密码。
- 调用 `auth.login()` 进行登录。
- 登录成功后自动获取用户信息并跳转至仪表盘。

### 12.2 注册页

文件：`src/pages/register.tsx`

功能：

- 用户输入用户名、邮箱、密码进行注册。
- 注册成功后自动登录并跳转至仪表盘。

### 12.3 忘记密码页

文件：`src/pages/forgot-password.tsx`

功能：

- 用户输入邮箱发送重置密码链接。

### 12.4 仪表盘页

文件：`src/pages/admin/dashboard.tsx`

展示统计卡片：

1. **用户总数**：累计注册用户数。
2. **今日活跃用户**：今日有活动的用户数。
3. **总生成次数**：累计 AI 生成次数。
4. **今日生成次数**：今日 AI 生成次数。

附加展示：

- 配额使用率进度条。
- 快速操作按钮（跳转到用户管理、推荐图管理）。

### 12.5 用户管理页

文件：`src/pages/admin/users.tsx`

功能：

- 表格展示用户列表。
- 支持按用户名/邮箱搜索。
- 分页展示（每页 20 条）。
- 展示用户信息：
  - 用户名
  - 邮箱
  - 角色（用户/管理员）
  - 配额使用情况（进度条 + 数值）
  - 状态（正常/禁用）
  - 创建时间

注意：当前编辑功能按钮已预留但处于 `disabled` 状态。

### 12.6 推荐图管理页

文件：`src/pages/admin/recommendations.tsx`

功能：

- 卡片网格展示推荐图列表。
- 支持按目标类型筛选（accessory/model）。
- 分页展示（每页 20 条）。
- 展示推荐图信息：
  - 图片预览
  - 标题
  - 描述
  - 目标类型（配饰推荐/模特推荐）
  - 排序值
  - 启用/禁用状态
- 支持新增、编辑、删除推荐图。
- 支持图片上传。

注意：排序通过编辑推荐图时调整 `sort_order` 字段实现，数值越小越靠前。

## 16. 与后端集成

管理后台与前台共用同一后端 FastAPI 服务。

本地开发推荐同时启动：

```bash

cd backEnd
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# 终端 2
cd frontEnd
npm run dev

# 终端 3
cd adminPanel
npm run dev
```

访问地址：

- 前台：`http://localhost:5173`
